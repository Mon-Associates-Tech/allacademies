# Product Overview

## Project Purpose
All Academies is a comprehensive school management and educational platform built with Laravel. It provides a multi-tenant SaaS solution for educational institutions to manage academic operations, digital libraries, assessments, and AI-powered learning tools.

## Value Proposition
- **Multi-tenant Architecture**: Supports multiple schools with isolated data and customizable settings
- **Role-based Access Control**: Manages diverse user roles (students, teachers, librarians, administrators, parents, authors)
- **AI-Powered Learning**: Integrates OpenAI for academic chat, content generation, and personalized learning experiences
- **Digital Library Management**: Complete book borrowing, subscription, and reading progress tracking system
- **Assessment & Evaluation**: Comprehensive quiz, examination, and assignment management with automated grading
- **Real-time Collaboration**: Live virtual sessions via BigBlueButton, messaging, forums, and note sharing

## Key Features

### Academic Management
- Academic year, period, level, and group organization
- Subject and topic hierarchy with subtopics
- Course outline creation and management
- Student academic progression tracking
- Report cards and grade scales
- Attendance tracking and management

### User Management
- Multi-role user system (superadmin, owner, admin, teacher, student, librarian, author, parent, accountant)
- User impersonation for support and testing
- Two-factor authentication
- Activity tracking and login history
- User preferences and customization
- Suspension and status management

### Digital Library
- Book catalog with categories and metadata
- Book borrowing and inventory management
- Digital book subscriptions (individual and group)
- Reading progress tracking with achievements
- Book reviews and ratings
- Audio book conversion support
- Book sharing between users and groups

### Assessment System
- Multiple question types (multiple choice, essay, true/false)
- Quiz generation and sessions
- Examination creation with sections
- Assignment management with submissions
- Automated grading for objective questions
- Essay assessment workflow
- Performance analytics

### AI-Powered Features
- Academic chat with OpenAI integration
- Token-based subscription system for AI usage
- Content generation (quizzes, examinations, worksheets)
- Personalized learning recommendations
- Multiple AI model support (GPT-3.5, GPT-4)
- Usage tracking and analytics

### Communication & Collaboration
- Internal messaging system with attachments
- Forum with categories, topics, and moderation
- Note-taking with sharing capabilities
- Virtual sessions via BigBlueButton
- Session recordings and reminders
- Real-time notifications

### Financial Management
- School fee structures and payment tracking
- Subscription management with multiple packages
- Payment integration with Paystack
- Subaccount management for schools
- Financial aid tracking
- Incremental pricing tiers

### Media Management
- File upload and storage (AWS S3 support)
- Image processing with Intervention Image
- PDF content extraction
- Video and audio file handling
- Media attachments for various entities

## Target Users

### Primary Users
- **School Administrators**: Manage school operations, users, and settings
- **Teachers**: Create lessons, assignments, assessments, and track student progress
- **Students**: Access learning materials, complete assignments, take assessments
- **Librarians**: Manage book inventory, borrowing, and subscriptions
- **Parents**: Monitor student progress and communicate with teachers

### Secondary Users
- **Authors**: Publish and manage books in the platform
- **Superadmins**: Platform-wide management and support
- **Accountants**: Financial tracking and reporting

### Educational Institution Management
